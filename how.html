1. 1

    Add inputs

    Enter days until exam, hours per day, and build subjects with topics and subtopics. Set priority weights per subject. Or pick a pre-filled template (JEE, NEET, UPSC, DBMS).

  2. 2

    Generate schedule

    The planner distributes time across subtopics by priority weight. Revision slots are inserted every 3 sessions, and optional daily breaks are scheduled automatically.

  3. 3

    Review, track, and practice

    See a day-wise timeline. Mark sessions done to track progress, use the 🍅 Pomodoro timer for focus, take AI-powered quizzes (add your Anthropic API key in Settings), and write personal notes per subtopic.

  4. 4

    Save, export, and revisit

    Save plans locally with version tracking. Export to CSV for spreadsheets or .ics to add directly to Google Calendar or Apple Calendar. Revisit saved plans from the Saved Plans page anytime.
