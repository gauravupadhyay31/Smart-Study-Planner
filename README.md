# 📚 Smart Study Planner

<div align="center">

### Plan Smarter. Study Better.

An AI-powered study planning application that automatically creates balanced day-wise schedules from your subjects, topics, and subtopics. Designed for students preparing for exams with progress tracking, quizzes, reminders, and productivity tools.

## ✨ Features

### 📅 Smart Study Plan Generation
- Convert subjects, topics, and subtopics into a complete study schedule
- Priority-based time allocation
- Automatic day-wise planning
- Revision slot generation
- Break session scheduling

### 📊 Progress Tracking
- Mark study sessions as completed
- Visual progress monitoring
- Daily and overall completion statistics
- Session-wise performance tracking

### 🤖 AI-Powered Learning
- Generate quizzes using AI
- Practice topic-specific questions
- Improve retention through active learning

### 🍅 Productivity Tools
- Built-in Pomodoro focus timer
- Session notes
- Revision reminders
- Quick resource access

### 🔔 Reminders & Notifications
- Browser notifications
- WhatsApp reminders
- Exam preparation alerts

### 📤 Export & Save
- Save study plans locally
- Export as CSV
- Export as Calendar (.ics)
- Revisit saved plans anytime

## 🚀 How It Works

### Step 1: Add Inputs
Enter:
- Days until exam
- Study hours per day
- Subjects
- Topics
- Subtopics
- Priority weights

### Step 2: Generate Schedule
The planner automatically:
- Distributes study time
- Creates daily schedules
- Inserts revision sessions
- Adds break slots

### Step 3: Study & Track Progress
- Complete sessions
- Mark tasks as done
- Use AI quizzes
- Take notes
- Use the Pomodoro timer

### Step 4: Save & Export
- Save plans locally
- Export to CSV
- Export to Calendar (.ics)
- Reuse plans anytime

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/smart-study-planner.git
```

### Navigate to the Project

```bash
cd smart-study-planner
```

### Run the Application

Open:

```bash
index.html
```

in your browser.

No backend or additional installation required.
